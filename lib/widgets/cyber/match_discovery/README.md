# Match discovery component library

Import ../match_discovery.dart. Existing public symbols remain available.

- presentation.dart: formatting, type and semantic accent decisions.
- status.dart / plate.dart: reserved lifecycle header, continuous frame and one-time entrance.
- primitives.dart / outcome.dart: quiet VS, two-line names, action/progress and full-height percentage controls.
- fixture.dart / events.dart / market.dart / mission.dart / reveal.dart: feature-aware card variants.
- layout.dart: equal paired rows and accessibility collapse.

Part files form one Dart library, preserving private implementation visibility without circular imports.
Pricing, permission, settlement and navigation remain outside the visual primitives.
Shared numeric values come from design/match-discovery.json and generated local adapters.
